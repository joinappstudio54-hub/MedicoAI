# edamam.com — recipes: salad (Category)
Source: https://www.edamam.com/results/recipes/?search=salad
The `urls.json` file in this repository was generated by scraping that search results page.

This project scrapes recipe pages (category: "salad") from Edamam and saves basic recipe data and images.

Functionality
- Reads URLs from `urls.json`.
- Visits each recipe page using Selenium + ChromeDriver (managed by `webdriver-manager`).
- Extracts: title, image URL (downloads image), ingredients, instructions link, nutrition, and source URL.
- Saves results incrementally to `recipes.json` and stores images in `recipe_images/`.

Requirements
- See `requirements.txt` (selenium, webdriver-manager, requests, etc.).

Quick start
1. Install dependencies:

```powershell
pip install -r requirements.txt
```

2. Run the scraper from the repository root:

```powershell
python scraper.py
```

Outputs
- `recipes.json` — JSON array with scraped recipe objects (written incrementally).
- `recipe_images/` — downloaded recipe images.
