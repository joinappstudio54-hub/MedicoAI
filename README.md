# Recipe Scraper

This repository contains a recipe scraping toolkit for collecting recipe URLs and scraping recipe details from Edamam search results.

## Project Structure

- `urls_scraper.py` - Scrapes recipe URLs from Edamam search pages using a list of keywords.
- `recipe_scraper.py` - Scrapes recipe details from the collected recipe URLs and saves them to `recipes.json`.
- `urls.json` - Output file generated by `urls_scraper.py`. It stores scraped recipe URLs grouped by search term.
- `recipes.json` - Output file generated by `recipe_scraper.py`. It stores scraped recipe metadata.
- `progress.json` - Checkpoint file used by `urls_scraper.py` to persist completed search terms and resume scraping.
- `recipe_images/` - Directory where recipe images are downloaded when scraping recipes.
- `requirements.txt` - Python dependencies required to run the scrapers.

## Requirements

Install Python 3.9+ and the dependencies:

```bash
pip install -r requirements.txt
```

## Usage

1. Run the URL scraper first to build `urls.json`:

```bash
python urls_scraper.py
```

2. Once `urls.json` is created, run the recipe scraper to fetch recipe details:

```bash
python recipe_scraper.py
```

## What It Scrapes

- `urls_scraper.py` navigates Edamam recipe search pages for a large set of search terms.
- It scrolls each search page, clicks "Show More" when available, and extracts recipe links.
- Scraped URLs are stored in `urls.json` under lowercase keys of each search term.

- `recipe_scraper.py` loads URLs from `urls.json` and extracts recipe fields such as:
  - `title`
  - `image`
  - `image_path`
  - `ingredients`
  - `instructions`
  - `nutrition`
  - `source_url`

## Notes

- `urls_scraper.py` uses `progress.json` to avoid re-scraping terms that are already processed.
- `recipe_scraper.py` downloads recipe images into `recipe_images/` and avoids duplicate filenames.
- Both scripts use Selenium and require a Chrome browser compatible with `webdriver-manager`.
