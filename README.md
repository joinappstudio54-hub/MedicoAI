# Biryani Recipe Scraper (Edamam)

This project scrapes recipe pages for the "biryani" search results on Edamam and saves basic recipe data and images.

Source search page:

https://www.edamam.com/results/recipes/?search=biryani

Overview
- Reads recipe URLs from `urls.json` (generated by `url_scraper.py`).
- Visits each recipe page using Selenium + ChromeDriver (managed by `webdriver-manager`).
- Extracts: title, image (downloaded to `recipe_images/`), ingredients, instructions link, nutrition info, and source URL.
- Saves results incrementally to `recipes.json` and stores images in `recipe_images/`.

Repository structure

- `urls.json` — list of recipe page URLs (search results for "biryani").
- `scraper.py` — main scraper that visits each recipe URL and extracts data.
- `url_scraper.py` — helper to generate `urls.json` from Edamam search results.
- `recipes.json` — output file written incrementally by `scraper.py`.
- `recipe_images/` — directory where recipe images are downloaded.
- `requirements.txt` — Python dependencies.

Requirements

- Python 3.8+ recommended.
- See `requirements.txt` for required packages (e.g., `selenium`, `webdriver-manager`, `requests`).

Quick start

1. Install dependencies:

```powershell
pip install -r requirements.txt
```

2. (Optional) Re-generate `urls.json` for a different search term using `url_scraper.py`:

```powershell
python url_scraper.py
```

3. Run the scraper from the repository root:

```powershell
python scraper.py
```

Outputs

- `recipes.json` — JSON array with scraped recipe objects (written incrementally).
- `recipe_images/` — downloaded recipe images.
